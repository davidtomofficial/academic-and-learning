# Rights and provenance

[Back to the collection](README.md)

No collection-wide license is granted. Existing grants, file-specific notices, author names and course attributions remain applicable. Relocating the owner's work into this collection does not replace those terms.

## Reference archives

The original `cpp-Examples`, `Python`, `SQL` and `Web-App-Development` repositories are retained for reference, including their files, branches and Git history. The [source manifest](SOURCE-MANIFEST.json) records exact original commits, blob hashes and paths. Original-source URLs may require repository access; use the project links in the [collection index](README.md) to browse public snapshots.

The collection is a curated snapshot, not a full Git-history import. Documentation changes are recorded in the manifest. Earlier snapshot copies omit numeric student identifiers from source comments while retaining author, course and date.

## SQL final assignment

The SQL script, DOCX report and PDF ERD are preserved together without changes. The report's notice names David Tom and Fictitious Database Services Inc., a fictional entity in the coursework, and reserves rights in the report and accompanying material. That notice remains intact. The owner's November 7, 2026 consolidation instruction authorizes this relocation; it does not create a new reuse license or replace file-specific terms.

The historical SQL, C++ and Python root READMEs contain a GPL version 3 statement. Those statements are retained in the provenance directories. They are not treated as proof that every supplied course, media or data asset is covered.

## Material retained in reference archives

The public snapshots omit material whose separate provenance remains unresolved, including supplied C++ templates and tests, the Tic-Tac-Toe source with separate attribution, literary fixtures and derived output, the Python notebook and word list, and selected web/app media, quotations and course instructions. Six historical executables and the generated dependency placeholder also remain in the archives.

The web coursework includes authored HTML/CSS and planning files. The app snapshot includes authored source, configuration and its recorded lockfile. Original asset and dependency references are unchanged, so partial projects may not build or run. The bundled Modernizr build remains in the reference archive with its existing notice.

The source manifest identifies every included or retained file. Private preservation records retain the earlier review decisions. No existing source history or original notice is deleted by this consolidation.
