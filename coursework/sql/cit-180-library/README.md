## Historical context

The source headers identify December 10, 2023; the original upload history begins earlier in December. These dates are retained as recorded. The report describes a fictional system, and its illustrative database sizes are part of that assignment scenario.

The script drops and recreates example tables and views. Review it in a separate practice database before attempting execution. Current SQL Server compatibility and successful execution have not been revalidated.
