Some source, data, media and supplied course material remain at their original locations pending named review. Partial snapshots are for source inspection and may not build or run.

Original repositories, commits, dates and history remain unchanged. This is a curated snapshot, not an import of complete Git history. Existing repository and file-specific rights continue; no blanket license is assigned here. See [Rights and provenance](RIGHTS-AND-PROVENANCE.md) and [source manifest](SOURCE-MANIFEST.json).
