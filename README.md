## Preservation and rights

The original repositories retain their files, branches and complete Git history for reference. This collection contains curated snapshots with exact original revisions recorded in the [source manifest](SOURCE-MANIFEST.json). Original-source URLs are provenance references and may require archive access.

The collection contains 109 source and provenance files, plus this index, the [rights note](RIGHTS-AND-PROVENANCE.md) and the manifest. Another 44 mapped files remain in the reference archives, including historical executables, supplied course material and media with unresolved provenance. Existing notices and attributions are retained; no collection-wide license is assigned.
