## Technology notes

The ward-app prototype's committed `package.json` specifies **Expo SDK 51**, **React 18.2.0**, and **React Native 0.74.1**, along with React Navigation dependencies. Those versions describe the repository's historical state—not a current support or security assurance. The `web` script exists, but a working browser build has **not** been verified; its web-specific dependencies and compatibility need review. The [prototype README](../../early-projects/community-app/README.md) describes its current historical scope, source structure and unverified build/deployment status.

The CSN Cafe project is a coursework demonstration. Its sample pages and media should not be interpreted as an official College of Southern Nevada website, approved menus, or operational content.
